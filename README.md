# Envoyr

An AI-powered development environment orchestrator.

## Problem

Developers often spend time installing and configuring toolchains
that have operating-system-specific requirements.

## Vision

Envoyr accepts natural-language setup requests, researches official
documentation, plans an appropriate environment, executes approved
installation steps, and verifies the result.

## Initial scope

- Natural-language setup requests
- Official documentation research
- Environment planning
- Human-in-the-loop approvals
- Safe command execution
- Failure diagnosis and recovery
- Installation verification

## Required integrations

- Entire: coding-session context and checkpoints
- neatlogs: agent observability
- cfo.ai: infrastructure economics and business modelling

## Initial target

A verified developer-toolchain setup workflow, starting with
Midnight on Windows.
